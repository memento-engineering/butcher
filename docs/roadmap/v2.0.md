# v2.0

Goal: ecosystem integrations and large-scale features.

## Features

- TCE equivalent-mutant detection (kernel compile + hash compare)
- `dart analyze` second-line check on survivors
- GitHub/GitLab annotations; dashboard integration
- CI sharding
- History-file incremental analysis across runs

## Design guidance

- TCE is a filter stage between execution and reporting; survivors marked
  `Equivalent` (enum value exists since MVP).
- Sharding partitions by stable mutant ID; determinism guarantees shards are
  reproducible and disjoint.
- History file keys on mutant ID + source/test hashes recorded since v1.0.
