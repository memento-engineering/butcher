# v0.1

Goal: fast enough for daily use. First pub.dev release.

## Features

- Parallel execution: N workers, each with its own containment copy
- lcov ingestion → `NoCoverage` outcome + covered-code MSI
- `flutter test` support
- Config file + include/exclude globs
- Dart-specific operators (null-safety, cascade, async)
- Unhandled-syntax warning: log AST node kinds no mutagen handles
- pub.dev release

## Design guidance for later stages

- Scheduler assigns work to isolated workers; in v1.0 the unit of work changes
  from "mutant" to "mutant × covering test" — keep the queue generic.
- Coverage data model is per-line from the start; v1.0 extends it to
  per-test → lines. Don't hardcode "one coverage set per project".
- Config schema is public API once released; reserve names for known v1.0
  flags (`diff-base`, report options).
- The syntax warning's node-kind census is the raw data for the v1.0
  syntax-coverage metric; store it in the run result, not just the log.
