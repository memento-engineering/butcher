# Roadmap

Staged feature plan for the mutation testing tool described in
[../decisions/index.md](../decisions/index.md). Each stage prepares the seams
the next stage fills.

| Stage | Status | Goal | Details |
|---|---|---|---|
| MVP | complete | Usable on an existing Dart project: score, metrics, machine-readable output | [mvp.md](mvp.md) |
| v0.1 | release pending | Fast enough for daily use; first pub.dev release | [v0.1.md](v0.1.md) |
| v0.2 | planned | Operational control, calibration, broader Dart feedback | [v0.2.md](v0.2.md) |
| v1.0 | planned | CI-grade: no process per mutant, full reporting | [v1.0.md](v1.0.md) |
| v2.0 | planned | Ecosystem integrations and large-scale features | [v2.0.md](v2.0.md) |
