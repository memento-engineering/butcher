# Roadmap

Staged feature plan for the mutation testing tool described in
[../decisions/index.md](../decisions/index.md). Each stage prepares the seams
the next stage fills.

| Stage | Goal | Details |
|---|---|---|
| MVP | Usable on an existing Dart project: score, metrics, machine-readable output | [mvp.md](mvp.md) |
| v0.1 | Fast enough for daily use; first pub.dev release | [v0.1.md](v0.1.md) |
| v0.2 | Operational control and broader Dart feedback | [v0.2.md](v0.2.md) |
| v1.0 | CI-grade: compile-once architecture, full reporting | [v1.0.md](v1.0.md) |
| v2.0 | Ecosystem integrations and large-scale features | [v2.0.md](v2.0.md) |
