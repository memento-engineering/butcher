# v0.2

- Status: next; [plan](../plans/v0.2/index.md)

Goal: operational control and broader Dart feedback.

## Features

- Calibration reading: one instrumented pass verifies the suite, records
  coverage, and times every suite, replacing the separate collection run
  (ADR 0020)
- Half-life as a budget of silence, not of elapsed time (ADR 0006)
- Config file + include/exclude globs
- Dart-specific operators (null-safety, cascade, async)
- Unhandled-syntax warning: log AST node kinds no mutagen handles
- Interactive stale-lock prompt
- `--non-interactive` to abort on lock conflicts in CI

## Design guidance for later stages

- Config schema is public API. Reserve known v1.0 names such as `diff-base`
  and report options.
- Both features are prerequisites for v1.0: silence budgets are what let the
  reading be instrumented, and per-test timing is what orders exposures.
- Store the node-kind census in the run result, not just the log; v1.0 turns
  it into the syntax-coverage metric.
